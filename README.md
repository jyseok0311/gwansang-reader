# 관상 판독기 (觀相判讀器)

카메라로 정면 얼굴을 촬영하면 MediaPipe Face Landmarker로 478개 얼굴 지점을 측정하고,
전통 관상학의 삼정(三停)·오관(五官)·십이궁(十二宮)·오행(五行) 얼굴형 이론에 따라
재물운·애정운·직업운·건강운·대인관계운을 풀이해 주는 웹앱입니다. (오락용)

PC와 휴대폰(안드로이드·아이폰) 모두에서 동작하며, 얼굴 사진은 기기 밖으로 전송되지 않습니다.

## 실행

`start.bat`을 더블클릭하면 서버가 켜지고 브라우저가 자동으로 열립니다. 명령줄에서는 다음과 같습니다.

```bash
node server.js --open
```

필요한 것은 [Node.js](https://nodejs.org) 하나뿐입니다. 외부 패키지를 설치하지 않습니다.

## 휴대폰에서 쓰기

1. PC와 휴대폰을 **같은 와이파이**에 연결합니다.
2. PC 화면의 「휴대폰으로 보기」 QR 코드를 휴대폰 카메라로 찍습니다.
   서버 창에 나오는 `https://<PC의 IP>:5443` 주소를 직접 입력해도 됩니다.
3. "연결이 비공개가 아님" 경고가 나오면 **[고급] → [계속]**을 누릅니다.
   아이폰은 **[세부사항 보기] → [이 웹사이트 방문]**입니다.
   PC에서 직접 만든 인증서라서 나오는 경고입니다.
4. 카메라 권한을 **허용**합니다.
5. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

휴대폰이 접속되지 않으면 다음을 확인하세요.

- 처음 실행할 때 뜨는 Windows 방화벽 창에서 Node.js의 **개인 네트워크 허용**을 눌렀는지
- 캠퍼스·공용 와이파이는 기기끼리 연결을 막는 경우가 많습니다. 휴대폰 핫스팟에 PC를 연결하면 확실합니다.

`http://` 주소로 접속하면 브라우저 보안 정책 때문에 실시간 카메라를 쓸 수 없습니다.
이때는 촬영 버튼이 휴대폰 **기본 카메라 앱**을 열어 촬영하고, 나머지 분석은 똑같이 동작합니다.

## 카메라 권한

| 환경 | 방법 |
| --- | --- |
| PC Chrome·Edge | 주소창 왼쪽 자물쇠 아이콘 → 카메라 **허용** → 새로고침 |
| Windows | 설정 → 개인 정보 및 보안 → 카메라 → 카메라 액세스 켜기 |
| 안드로이드 Chrome | 주소창 왼쪽 아이콘 → 권한 → 카메라 허용 |
| 아이폰 Safari | 설정 → Safari → 카메라 → 허용 (또는 주소창 `가가` → 웹 사이트 설정) |

Claude 앱 안의 미리보기 브라우저는 카메라를 막아 두었습니다. 반드시 일반 브라우저에서 여세요.

## 주요 기능

- **실시간 촬영 가이드**: 거리·위치·고개 각도(3D)·눈 감음·웃음·입 벌림을 검사해 안내합니다.
- **자동 촬영**: 조건을 1.2초 유지하면 셔터가 자동으로 눌립니다. 끌 수도 있습니다.
- **흔들림 보정**: 촬영 직전 1.5초 동안의 프레임 측정값 중앙값으로 분석합니다.
- **사진 업로드**: 파일 선택이나 끌어다 놓기로 분석합니다. 돌아간 얼굴은 자세를 보정합니다.
- **결과 공유**: 휴대폰에서는 공유 시트로, PC에서는 PNG 파일로 결과 카드를 저장합니다.
- **오프라인 동작**: 판독 엔진과 모델을 `vendor/`에 포함해 인터넷 없이도 분석합니다.
  (웹폰트만 인터넷이 필요하며, 없으면 기본 글꼴로 표시됩니다.)
- **앱 설치(PWA)**: 홈 화면에 추가하면 전체 화면 앱처럼 실행됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (시작 / 카메라 / 분석 중 / 결과) |
| `style.css` | 디자인 (휴대폰 전체 화면 카메라, 노치 영역, 하단 고정 버튼) |
| `app.js` | 카메라, 실시간 가이드, 검출, 결과 렌더링, 결과 카드, 뒤로 가기, QR 코드 |
| `measure.js` | 랜드마크 3D 자세 보정(롤·요·피치)과 비율 측정 |
| `physiognomy.js` | 관상학 지식 베이스와 해석 엔진 (표준점수 기반 판정) |
| `server.js` | 로컬 서버 (HTTP + 휴대폰용 HTTPS, 인증서 자동 생성) |
| `sw.js`, `manifest.webmanifest`, `icons/` | 오프라인 캐시와 앱 설치 |
| `vendor/` | MediaPipe 판독 엔진(Apache-2.0)·얼굴 모델, QR 코드 생성기(MIT) |
| `certs/` | 자동 생성된 HTTPS 인증서. 개인키가 들어 있으니 공유하지 마세요. 서버는 이 폴더를 외부에 내보내지 않습니다. |
| `tools/` | 기준값 보정 스크립트와 표본 측정값 |

## 판정 기준값 보정

모든 판정은 표본 인구의 중앙값과 표준편차로 계산한 **표준점수**로 합니다.
그래서 특정 운이나 얼굴형으로 결과가 쏠리지 않고, 보통 사람은 77점 전후에 놓입니다.

- 표본: 공개 초상 사진 19명 (미국 의회 퍼블릭 도메인, 한국 공공누리 1유형). 사진은 보관하지 않고 측정값만 `tools/population-sample.json`에 번호로 남겼습니다.
- 한국인 사용자를 기준으로 삼기 위해 한국인 표본에 가중치 2.8을 줍니다.
- 표본 대부분이 웃는 공식 사진이라, 무표정 기준에 맞춰 웃는 사진의 입 폭을 1.2로 나눠 보정합니다.

표본을 늘리거나 바꾼 뒤 다음을 실행하면 새 기준값을 계산하고 분포를 확인할 수 있습니다.

```bash
node tools/calibrate-population.mjs
```

```bash
node tools/calibrate-population.mjs --check
```

새 사진의 측정값은 앱을 연 브라우저 콘솔에서 `await gwansang.measureUrl('사진주소')`로 얻을 수 있습니다.

## 주의

본 결과는 전통 관상학 이론에 기반한 오락용 콘텐츠이며 과학적·의학적 근거가 없습니다.
표본이 19명으로 작아서 기준값은 대략적인 값입니다.
