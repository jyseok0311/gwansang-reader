# 운명 판독기 (運命判讀器)

카메라로 정면 얼굴을 촬영하면 MediaPipe Face Landmarker로 478개 얼굴 지점을 측정하고,
전통 관상학의 삼정(三停)·오관(五官)·십이궁(十二宮)·오행(五行)·십자면상(十字面相) 이론에 따라
재물운·애정운·직업운·건강운·대인관계운을 풀이해 주는 웹앱입니다. (오락용)

PC와 휴대폰(안드로이드·아이폰) 모두에서 동작하며, 얼굴 사진은 기기 밖으로 전송되지 않습니다.

## 바로 사용하기

**https://jyseok0311.github.io/gwansang-reader/**

설치 없이 PC나 휴대폰 브라우저에서 위 주소를 열면 됩니다. 정식 HTTPS 주소라서 휴대폰에서도 인증서 경고 없이 카메라를 쓸 수 있습니다.

## 내 PC에서 실행

`start.bat`을 더블클릭하면 서버가 켜지고 브라우저가 자동으로 열립니다. 명령줄에서는 다음과 같습니다.

```bash
node server.js --open
```

필요한 것은 [Node.js](https://nodejs.org) 하나뿐입니다. 외부 패키지를 설치하지 않습니다.

## 휴대폰에서 쓰기

1. PC와 휴대폰을 **같은 와이파이**에 연결합니다.
2. PC 화면의 「휴대폰으로 보기」 QR 코드를 휴대폰 카메라로 찍습니다.
   서버 창에 나오는 `https://<PC의 IP>:5443` 주소를 직접 입력해도 됩니다.
3. "연결이 비공개가 아님" 경고가 나오면 **[고급] → [계속]**을 누릅니다.
   아이폰은 **[세부사항 보기] → [이 웹사이트 방문]**입니다.
   PC에서 직접 만든 인증서라서 나오는 경고입니다.
4. 카메라 권한을 **허용**합니다.
5. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

휴대폰이 접속되지 않으면 다음을 확인하세요.

- 처음 실행할 때 뜨는 Windows 방화벽 창에서 Node.js의 **개인 네트워크 허용**을 눌렀는지
- 캠퍼스·공용 와이파이는 기기끼리 연결을 막는 경우가 많습니다. 휴대폰 핫스팟에 PC를 연결하면 확실합니다.

`http://` 주소로 접속하면 브라우저 보안 정책 때문에 실시간 카메라를 쓸 수 없습니다.
이때는 촬영 버튼이 휴대폰 **기본 카메라 앱**을 열어 촬영하고, 나머지 분석은 똑같이 동작합니다.

## 카메라 권한

| 환경 | 방법 |
| --- | --- |
| PC Chrome·Edge | 주소창 왼쪽 자물쇠 아이콘 → 카메라 **허용** → 새로고침 |
| Windows | 설정 → 개인 정보 및 보안 → 카메라 → 카메라 액세스 켜기 |
| 안드로이드 Chrome | 주소창 왼쪽 아이콘 → 권한 → 카메라 허용 |
| 아이폰 Safari | 설정 → Safari → 카메라 → 허용 (또는 주소창 `가가` → 웹 사이트 설정) |

Claude 앱 안의 미리보기 브라우저는 카메라를 막아 두었습니다. 반드시 일반 브라우저에서 여세요.

## 관상 + 손금 + 사주 종합 분석

앱을 열면 바로 **관상 · 손금 · 사주** 세 단계 체크리스트가 첫 화면으로 나옵니다.
세 가지를 다 하지 않아도 **두 가지만으로** 종합해 줍니다. 순서도 상관없습니다.
한 가지만 보고 싶다면 그 카드를 마친 뒤 카드의 **「결과 보기」**를 누르면 그 결과만 볼 수 있습니다.

| 단계 | 하는 일 |
| --- | --- |
| 사주 | 양력·음력(윤달 포함) 생년월일과 태어난 시간(모르면 생략)을 입력 |
| 관상 | 정면 얼굴 촬영 또는 사진 올리기 |
| 손금 | 손가락을 펴고 손바닥을 촬영하거나 사진 올리기 |

**종합 결과**에는 다음이 나옵니다.

- **종합 점수와 등급**: 다섯 가지 운(재물·애정·직업·건강·대인관계)을 세 방면에서 각각 점수 내고, 관상 40%·손금 25%·사주 35% 비중으로 합칩니다. 빠진 방면이 있으면 남은 비중으로 다시 나눕니다.
- **세 방면의 오행**: 얼굴 형(木火土金水), 손 모양, 사주 일간의 오행이 서로 살려 주는 상생인지 누르는 상극인지 풀이합니다.
- **사주의 빈 기운 보완**: 사주에 비어 있는 오행을 얼굴이나 손의 기운이 채워 주는지, 반대로 겹쳐 지나친지 짚습니다.
- **엇갈림 표시**: 한 운을 두 방면이 크게 다르게 본 경우 "해석이 엇갈림"으로 알려 줍니다.
- **종합 총평과 결과 카드**: 다섯 문단의 총평과, 사주 여덟 글자·손금 선 사진이 든 저장·공유용 카드 이미지를 만듭니다.

### 손금 촬영 요령

- 밝고 고른 빛에서, 손바닥 전체가 화면에 크게 나오게 하세요. 손가락은 쭉 펴고 손가락 끝은 위로 향하게 합니다.
- 손등이 보이면 "손등이 보여요"로 알려 줍니다. 손이 움직이면 "잠시 멈춰 주세요"라고 안내하고, 멈추면 1.5초 뒤 자동으로 찍힙니다.
- 휴대폰에서는 화질이 좋은 **뒷면 카메라**가 기본입니다.

### 손금은 이렇게 읽습니다

1. 손 인식 모델(MediaPipe Hand Landmarker)로 손 관절 21개를 찾습니다.
2. 손목과 중지 뿌리를 잇는 축을 기준으로 손바닥을 똑바로 펴서 잘라 냅니다. 어느 손이든 엄지 쪽이 왼쪽으로 정렬됩니다.
3. 조명 얼룩을 지우고, 12개 방향으로 길게 늘인 필터로 어둡고 가는 주름을 찾습니다. 짧은 피부결은 걸러집니다.
4. 감정선·두뇌선·생명선·운명선이 있을 만한 해부학적 위치 범위를 정해 두고, 그 안에서 가장 뚜렷한 주름을 따라가는 최저 비용 경로를 찾습니다. 감정선은 두뇌선보다 위쪽에서만 찾습니다.
5. 각 선의 길이, 선명도, 끊김, 휘어짐, 기울기를 재서 풀이합니다. 손바닥 비율과 손가락·엄지 길이로 손의 오행(木火土金水)도 정합니다.

**한계**: 이 방식은 사진이 선명하고 손바닥이 정면일 때만 잘 맞습니다. 어둡거나 초점이 흐리거나 손이 많이 기울면 다른 주름을 잡을 수 있어, 결과 화면에 찾은 선을 사진 위에 그려 보여 주고 사진 상태가 나쁘면 알려 줍니다. 선별 기준값은 공개 손바닥 사진 6장의 측정 분포로 잡은 대략적인 값입니다(사진은 저장하지 않았습니다).

### 사주는 이렇게 계산합니다

- **연주·월주**: 절기를 기준으로 합니다. 태양의 위치(황경)를 천문 공식으로 계산해 입춘(315°)에서 해가, 30°마다 달이 바뀝니다. 2024년 입춘(2월 4일 17시 27분)과 분 단위로 일치하는지 확인했습니다.
- **일주**: 율리우스일로 60갑자를 셉니다. 1900~2049년 무작위 날짜로 한국천문연구원 기준 음력 라이브러리의 일진과 대조해 모두 일치했습니다.
- **시주**: 서울 경도(126.98°)에 맞춘 실제 태양시(표준시보다 약 32분 늦음)로 시각을 보정하고, 23시부터 다음 날 자시로 봅니다. 1908년 이후 한국 표준시 변경(+8:30, +9:00)과 1948~1960년·1987~1988년 서머타임을 반영합니다.
- **음력**: [korean-lunar-calendar](https://github.com/usingsky/korean_lunar_js)(MIT)로 양력으로 바꿉니다. 지원 범위는 1000~2050년입니다.
- **풀이**: 일간(日干)의 성격, 오행 분포와 빈·넘치는 기운, 신강·신약, 십성 분포, 띠를 풀이합니다.
- **다루지 않는 것**: 대운·세운, 신살, 격국·용신 등 정밀한 명리 풀이는 다루지 않습니다.
- **자체 검증**: `node tools/saju-check.mjs`로 일주 대조 2000일, 입춘 경계, 알려진 날짜, 서머타임 처리를 다시 확인할 수 있습니다.

## 얼굴형 분류

두 가지 전통 분류를 함께 써서 얼굴 윤곽 10가지 × 오행 기질 5가지, 모두 50가지 조합으로 풀이합니다.

- **십자면상(十字面相)**: 얼굴 윤곽을 열 글자에 빗댄 분류입니다. 田(네모)·由(아래가 넓음)·甲(역삼각)·申(마름모)·同(직사각)·王(각진 뼈대)·圓(둥긂)·目(길쭉)·用(좌우가 다름)·風(이마·턱이 넓고 볼이 갸름)자형입니다. 이마 폭·턱 폭·턱 각도·턱 끝 폭·얼굴 길이·좌우 균형으로 가장 가까운 형을 고릅니다.
- **오행 기질(五行形)**: 목·화·토·금·수 다섯 기운 가운데 주된 기운과 섞인 기운을 봅니다.

## 총평

총평은 다섯 문단으로, 사람마다 다른 조합으로 엮입니다.

1. **윤곽과 기질**: 십자면상 윤곽과, 주된 오행·섞인 오행의 상생·상극 관계(20가지 조합)를 풀이합니다.
2. **가장 두드러진 부위**: 12개 부위 중 그 사람에게서 가장 튀는 두 곳을 "스무 명 중 한 명꼴로 드물게"처럼 대략적인 빈도와 함께 짚습니다.
3. **인생 흐름**: 삼정 중 가장 두터운 시기와 가벼운 시기의 조합으로 흐름을 풀이합니다.
4. **다섯 운**: 가장 밝은 운과 가장 조용한 운의 조합(20가지)마다 다른 해석을 줍니다.
5. **마무리**: 등급·윤곽·오행에 따라 달라집니다.

가상 인물 27명으로 비교하면, 두 사람의 총평에서 글자까지 같은 문장의 비율이 26%에서 6%로 줄었습니다.

## 원근 보정

휴대폰 셀카는 얼굴과 렌즈가 30~40cm로 가까워 코·눈은 크게, 얼굴 옆선은 좁게 찍힙니다. 보정하지 않으면 모든 사람이 비슷한 얼굴형으로 몰립니다.

- **카메라 촬영**: 화면 속 얼굴 크기와 카메라 화각(휴대폰 약 80도, 노트북 약 72도로 가정)으로 촬영 거리를 추정합니다. 표준 얼굴 3D 모델로 그 거리의 왜곡량을 계산해 빼 줍니다.
- **사진 업로드**: 사진 촬영 정보(EXIF)에 35mm 환산 초점거리가 있으면 같은 방식으로 보정합니다. 촬영 정보가 없거나 잘라낸 사진이면 보정하지 않습니다.
- **웃는 사진**: 업로드 사진은 표정 검사를 거치지 않으므로, 웃는 얼굴이면 입 너비를 무표정 기준으로 보정합니다.
- **한계**: 실제 카메라 화각이 가정과 다르면 보정이 일부만 됩니다. 화각이 8도 달라도 왜곡의 약 75%는 제거됩니다.

## 주요 기능

- **실시간 촬영 가이드**: 화면의 타원을 기준으로 거리·위치(왼쪽·오른쪽·위·아래)·고개 각도(3D)·눈 감음·웃음·입 벌림을 검사해 안내합니다.
- **화면 맞춤**: 카메라가 보내는 영상 비율과 휴대폰 화면 비율이 달라도 얼굴이 한쪽으로 치우치지 않게 배치합니다. 세로·가로 화면 모두 지원합니다.
- **자동 촬영**: 조건을 1.2초 유지하면 셔터가 자동으로 눌립니다. 끌 수도 있습니다.
- **흔들림 보정**: 촬영 직전 1.5초 동안의 프레임 측정값 중앙값으로 분석합니다.
- **사진 업로드**: 관상·손금 카드의 「🖼 사진」으로 올리거나, 첫 화면에 사진을 끌어다 놓으면(관상으로 분석) 됩니다. 돌아간 얼굴은 자세를 보정합니다.
- **결과 공유**: 휴대폰에서는 공유 시트로, PC에서는 JPG 파일로 결과 카드를 저장합니다.
- **휴대폰 배려**: 촬영 중 화면 꺼짐 방지, 데이터 절약 모드에서는 엔진을 미리 받지 않음, 느린 망에서는 3초 뒤 저장된 화면을 먼저 표시합니다.
- **오프라인 동작**: 판독 엔진과 얼굴·손 인식 모델, 음력 변환을 `vendor/`에 포함해 인터넷 없이도 분석합니다. 손 인식 모델(약 8MB)은 손금을 처음 볼 때 내려받습니다.
  (웹폰트만 인터넷이 필요하며, 없으면 기본 글꼴로 표시됩니다.)
- **앱 설치(PWA)**: 홈 화면에 추가하면 전체 화면 앱처럼 실행됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (첫 화면 종합 분석 허브 / 사주 입력 / 카메라 / 분석 중 / 관상·손금·사주·종합 결과) |
| `style.css` | 디자인 (휴대폰 전체 화면 카메라, 노치 영역, 하단 고정 버튼) |
| `app.js` | 카메라, 실시간 가이드, 검출, 결과 렌더링, 결과 카드, 뒤로 가기, QR 코드 |
| `measure.js` | 랜드마크 3D 자세 보정(롤·요·피치), 비율 측정, 촬영 거리 추정과 원근 보정 |
| `perspective.js` | 거리별 원근 보정표 (`tools/perspective-table.mjs`가 자동 생성) |
| `physiognomy.js` | 관상학 지식 베이스와 해석 엔진 (십자면상·오행·삼정·십이궁, 표준점수 기반 판정) |
| `saju.js` | 사주 계산(절기·일주·시주·음력·서머타임)과 풀이 |
| `palm.js` | 손바닥 펴기, 주름 검출, 선 따라가기, 선 특징 측정 (화면과 무관한 순수 영상 처리) |

## 판정 기준값 보정

모든 판정은 표본 인구의 중앙값과 표준편차로 계산한 **표준점수**로 합니다.
그래서 특정 운이나 얼굴형으로 결과가 쏠리지 않고, 보통 사람은 77점 전후에 놓입니다.

- **표본**: AI(StyleGAN)가 만든 **가상 인물**(실존하지 않는 사람) 얼굴 61장입니다. 실존 인물 사진은 쓰지 않습니다.
- **보관 방식**: 사진은 저장하지 않고 측정값만 `tools/population-sample.json`에 번호로 남겼습니다.
- **제외 기준**: 어린이로 보이는 사진, 만화처럼 보정된 사진, 고개를 좌우 12도·상하 16도 넘게 돌린 사진은 뺍니다. 그래서 실제 계산에는 44장이 쓰입니다. 턱 각도·턱 끝 폭은 이 측정을 추가한 뒤 받은 27장으로 계산합니다.
- **웃음 보정**: 표본에 웃는 얼굴이 많아, 무표정 기준에 맞춰 웃는 사진의 입 폭을 1.2로 나눠 보정합니다.
- **균형 보정**: 오행 기질·다섯 운·십자면상이 한쪽으로 쏠리지 않도록 표본 기준 보정값을 둡니다.

표본을 늘리거나 바꾼 뒤 다음을 실행하면 새 기준값을 계산하고 분포를 확인할 수 있습니다.

1. 기준값(POP)을 계산해 `physiognomy.js`에 붙여 넣습니다.

```bash
node tools/calibrate-population.mjs
```

2. 균형 보정값(FACE_TYPE_OFFSET·FORTUNE_OFFSET·SIPJA_NORM)을 계산해 `physiognomy.js`에 붙여 넣습니다.

```bash
node tools/calibrate-population.mjs --offsets
```

3. 분포를 확인합니다.

```bash
node tools/calibrate-population.mjs --check
```

측정 방식을 바꿨다면 원근 보정표도 다시 만듭니다.

```bash
node tools/perspective-table.mjs
```

새 사진의 측정값은 앱을 연 브라우저 콘솔에서 `await gwansang.measureUrl('사진주소')`로 얻을 수 있습니다.
표본을 추가할 때는 가상 인물 사진이나 본인이 동의한 사진만 쓰세요.
